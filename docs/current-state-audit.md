# EchoClass current-state audit

This historical record describes the original private development and deployment context. The public scientific export excludes its legacy media, repository history and runtime data; see [the public-snapshot note](public-snapshot.md) for the current artifact scope. Original external key rotation and production acceptance remain unverified.

Audit date: 2026-08-20  
Audited baseline: source archive supplied for Milestone 0  
Target version: `3.0.0-alpha.1`

The source is a Node.js, native JavaScript, server-rendered HTML, and SQLite application. No repository evidence supports describing it as Next.js, Supabase, automated computer vision, a digital twin, or a validated optimisation system.

## Secret and personal-data handling

- The audit detected a real-key pattern only in the source archive's `.env`.
- No secret value is reproduced in this repository or report.
- The sanitized repository contains no `.env`, database, WAL/SHM, runtime user JSON, runtime record JSON, or practice-answer file.
- The included CSV and built-in demo records use anonymous synthetic identifiers.

## Data and route inventory notes

The active persistence layer creates `migrations`, `classes`, `users`, `records`, `sessions`, `login_attempts`, `audit_logs`, `resources`, and `ai_questions`. `users`, `records`, `sessions`, `login_attempts`, and `audit_logs` have active code paths. `classes` receives minimal seed-side writes. `resources` and `ai_questions` do not have a complete active workflow.

The current application retains server-rendered pages and APIs for authentication, records, review actions, analytics, AI proxying, practice results, health, metrics, and static materials. Milestone 1 should formalize route ownership without changing public paths.

## Baseline conclusion

The repository is suitable for continued local development after the automated checks pass. It is not ready for public release until the previously exposed key is rotated and material provenance is confirmed. It is not ready for real classroom data until demo/production identity policy and durable file storage are completed.
