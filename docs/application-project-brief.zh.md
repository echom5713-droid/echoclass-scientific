# EchoClass：保留科学结果背后的证据

[English](application-project-brief.en.md) · [源码与运行说明](../README.md)

**申请项目附录草稿 · 3.0.0-beta.25 · 合成数据演示**

EchoClass 是围绕化学实验记录开发的 Node.js/TypeScript、SQLite 与 Python 项目。核心问题很具体：测量被修正，或教师改变审核决定后，早先的计算还能否解释和复现？

系统保留原始提交，以追加事件记录审核，并封存科学报告实际使用的输入。本地 Python 进程在 Node 的管理下计算描述性统计、均值的 bootstrap 区间及探索性的浓度响应拟合。报告将“已测条件中的最佳”与“未经测量的模型候选”分开。

## 一个案例，以及它的边界

可复现案例包含四个氯化铵浓度下的 20 条虚构记录。1% 与 3% 的平均精油得率同为 9%。组均值的二次拟合指向 2% 附近，但案例在这里没有测量。

另一个特意构造的响应在四个已测浓度上完全相同，在它们之间却不同。因此，相同的观测输入与模型结果，可以对应不同的已知未测响应。固定方法研究在五种合成情景、十二个种子上比较常数、线性和二次模型，同时保留反例与有利案例。

后续研究先选定新浓度，再模拟测量结果。在两个完全指定的假设、已知且独立的高斯噪声（标准差 2 个百分点）、三次重复、相同先验概率及错误代价下，测量 2% 的理论分类错误概率约为 4.16%。重复原有点的错误概率为 50%，因为两项预测相同。这只是受限的假设判别计算，不是已经找到真实化学最优条件的证据。

公开阅读入口默认英文，支持中文切换。两种语言使用相同的数值表、公式与交互计算。本版原课堂工作流程仍保留中文。

## 简短演示顺序

1. 打开 `/`，检查并列的已测均值与未测候选，再切换 EN 和中文。
2. 打开 `/engineering#next-measurement`，比较 1% 与 2%，然后改变噪声和重复次数。先解释假设，再解释概率。
3. 运行 `npm run scientific:demo -- --text`，顺着代码查看封存输入和审核路径。README 提供方法研究与后续研究的运行命令。
4. 讲清一个实际复现的失败及其回归测试，不把测试总数当作项目成效。

## 开发工具与项目证据

AI 工具参与了实现、测试、调试、文档和界面工作。[开发说明](engineering-notes.md#development-and-tool-assistance)记录了这些协作。源码与执行的检查说明系统行为，个人贡献需要依据实际完成的工作判断。

双语 `/walkthrough` 页面和[证据追踪命令](project-trace.zh.md)把一条具体观测与审核、保存的输入摘要及实际计算的组均值连接起来。分离副本练习演示摘要不匹配，不写入记录或报告。

项目没有确立真实课堂收益、提取效果、抗菌效果、独立人工验收或大规模计算能力。统计与安全审查仍未完成。科学源码快照移除了权限未确认的旧素材和私有运行数据；[公开快照说明](public-snapshot.md)记录其范围，历史部署与独立验收分别处理。

## 用两种语言展示项目

公开项目页、账号页，以及科学分析、报告解释、CSV 和附件操作默认英文，并可切换中文。英文阅读说明由引用的结构化字段生成；原解释与来源原值可以展开核对，显示的证据摘要仍对应这些原始内容。切换语言也保留已保存的重试标识，不会因显示偏好暗中创建另一份分析、导入或上传。旧课堂页面仍为中文。

这里有一个可讲清的设计决策：翻译后的展示不应覆盖已经按原始字节定义身份的证据。实现与验证见[显示语言与证据边界](operation-language.md)。
